Простой мессенджер для обмена сообщениями в реальном времени.
Этот проект — небольшой чат, в котором пользователи могут отправлять и получать сообщения. Сделан для практики работы с фронтендом/бэкендом и логикой общения между пользователями.

 Функции
- Отправка сообщений
- Отображение чата в реальном времени
- Простой и понятный интерфейс
